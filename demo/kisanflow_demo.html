Agentic concepts demonstrated: dynamic orchestration (routing changes for returning vs. new borrowers), explicit tool calls with a visible trace, a Verifier agent that can reject the Forecasting Agent's own output, a rule-based guardrail fallback when confidence is too low to trust, persistent cross-season memory, and retrieval-augmented grounding for the farmer-facing advisory text. Crop economics use real government-published baselines (above); weather/mandi/UPI signals themselves are still simulated toggles, not live API calls.
